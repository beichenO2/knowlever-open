# 相关接收技术

## 定义
相关接收是雷达信号检测中通过分析信号与噪声相关性差异实现目标检测的技术手段，属于信号处理领域的核心方法。该技术通过计算信号与参考信号的互相关函数，利用信号与噪声在统计特性上的差异实现目标检测，广泛应用于被动雷达和主动雷达系统。

## 详细属性
| 参数 | 规格 | 工作条件 | 适用范围 |
|------|------|----------|----------|
| 信号类型 | 实信号/复信号 | 高斯噪声环境 | 被动雷达/主动雷达 |
| 噪声类型 | 白噪声/有色噪声 | 独立同分布 | 低信噪比场景 |
| 输出特性 | 自相关函数/互相关函数 | 信号相关时间 | 距离/速度测量 |
| 计算复杂度 | O(N²) | 实时处理 | 多目标检测 |

## 工作原理
### 自相关接收
自相关接收通过计算接收信号与自身延迟版本的乘积积分，其数学表达式为：
```
Cx(τ) = ∫x(t)x*(t-τ)dt
```
该方法无需预知信号形式，适用于被动雷达处理。当τ足够大时，输出主要反映信号自相关特性，噪声相关项趋于零。

### 互相关接收
互相关接收需要预先知道信号形式，通过计算接收信号与本地参考信号的互相关函数实现检测：
```
C12(τ) = ∫x1(t)x2*(t-τ)dt
```
其中x1(t)为接收信号，x2(t)为本地参考信号。当τ=tr（回波延迟时间）时，输出达到峰值，此时C12(τ)=Cs(0)+Csn(tr)，信号成分显著高于噪声。

## 使用场景与优缺点
### 应用场景
- 被动雷达：无需发射信号，通过分析环境信号实现检测
- 距离测量：利用相关峰位置确定目标距离
- 多目标分辨：通过不同延迟时间区分多个目标

### 优点
- 不依赖信号先验知识（自相关）
- 抗干扰能力强（噪声相关项自动衰减）
- 可实现高精度距离测量

### 缺点
- 计算复杂度高（O(N²)）
- 需要精确控制延迟时间（互相关）
- 对多普勒频移敏感

## 原文证据
1. "自相关接收：不需要预先知道信号形式，易于实现，多用于被动雷达处理"
2. "互相关接收：必须预先知道信号形式，多用于主动雷达接收处理"
3. "C12(τ) = ∫x1(t)x2*(t-τ)dt 为其互相关函数"
4. "当τ=tr时，C13(τ)=Cs(0)+Csn(tr)=Cs(0)"
