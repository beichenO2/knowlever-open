# 振幅法测角

## 定义
振幅法测角是通过分析雷达天线接收的回波信号幅度变化规律，确定目标方位角的测量技术。该方法属于雷达角度测量原理体系中的重要实现方式，与相位法测角共同构成角度测量的核心技术框架。

## 详细属性
| 参数 | 规格 | 工作条件 | 适用范围 |
|------|------|----------|----------|
| 方法类型 | 振幅法 | 需要天线方向图特性 | 短距离目标跟踪 |
| 测量精度 | ±20%θ0.5（最大信号法） | 无明显多值性问题 | 静态目标定位 |
| 系统复杂度 | 中等 | 需要波束扫描控制 | 警戒雷达系统 |
| 抗干扰能力 | 一般 | 易受环境噪声影响 | 非密集目标场景 |

## 工作原理
### 最大信号法
当天线扫描过程中接收到最强回波信号时，天线指向即为目标方向。该方法利用信号能量最大化特性，但存在精度差（±20%θ0.5）和无法判别误差方向的缺陷。其数学表达为：

```
θ = argmax_{φ} |S(φ)|
```

### 等信号法
采用两个重叠波束，当目标位于两波束交叠轴时，两波束接收信号相等。通过同时波瓣法或顺序波瓣法实现，具有精度高（提升一个数量级）、可判别方向和抗干扰能力强的特点。其核心公式为：

```
S1(φ) = S2(φ) → φ = θ_target
```

## 使用场景与优缺点
### 适用场景
- 短距离目标定位（如火控雷达）
- 静态目标跟踪系统
- 需要快速响应的警戒雷达

### 优点
- 灵敏度高，能充分利用信号能量
- 实现简单，系统成本较低
- 抗起伏干扰能力较强

### 缺点
- 精度受限（最大信号法）
- 无法判别误差方向（最大信号法）
- 需要精确控制波束扫描

### 注意事项
- 避免多目标干扰导致信号叠加
- 需要定期校准天线方向图
- 适用于非密集目标环境

## 原文证据
> "利用天线收到的回波信号幅度来做角度测量。幅度变化规律取决于天线方向图以及天线的扫描方式。"

> "最大信号法：天线扫描过程中收到最强回波时，天线所在指向为目标方向。优点：灵敏度高，能充分利用信号能量；缺点：精度差，20％θ0.5，不能判别误差方向"

> "等信号法：利用两个相同且部分重叠的波束...精度提高一个数量级。"
