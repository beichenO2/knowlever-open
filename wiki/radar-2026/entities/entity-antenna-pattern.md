# 天线方向图

## 定义
天线方向图（Antenna Pattern）是描述天线辐射特性随空间方向变化的数学函数，表征天线在不同方位角和仰角方向上的辐射强度分布。作为雷达系统角度测量的基础物理模型，它直接决定了相位法和振幅法测角的可行性，属于雷达原理体系中的核心数据结构。

## 详细属性
| 参数 | 规格 | 说明 |
|------|------|------|
| F(θ) | 0 ≤ F(θ) ≤ F(0) | 方向图函数值始终小于等于主瓣最大值 |
| θ0.5 | 半功率宽度 | 主瓣宽度的量化指标，典型值为1°~5° |
| 对称性 | F(θ) = F(-θ) | 方向图关于法线方向对称 |
| 主瓣/副瓣 | 10dB~20dB分界 | 主瓣包含最大辐射方向，副瓣为次级辐射区域 |
| 工作频率 | 100MHz~100GHz | 适用不同雷达系统的工作频段 |
| 极化特性 | 线极化/圆极化 | 影响目标回波信号强度 |

## 工作原理
天线方向图由电磁波传播特性与天线结构共同决定：
1. **物理基础**：天线对不同方向到达的电磁波具有不同的振幅和相位响应，这种差异源于天线阵列的几何排列和馈电方式
2. **数学表达**：方向图函数F(θ)描述辐射强度随方向变化的规律，典型函数包括余弦函数、高斯函数和辛克函数
3. **波束特性**：主瓣（主波束）包含最大辐射方向，其宽度θ0.5决定角分辨力；副瓣（旁瓣）存在方向性畸变，可能引入测角误差

## 使用场景与特性
### 应用场景
- 雷达角度测量：作为相位法和振幅法测角的物理基础
- 天线波束设计：确定辐射方向和覆盖范围
- 目标定位：通过方向图特性实现空间定位

### 优缺点
| 优点 | 缺点 |
|------|------|
| 高方向性：集中能量提高探测距离 | 副瓣干扰：可能引入测角误差 |
| 宽带兼容：适应不同频段工作 | 机械扫描限制：波束转向速度受限 |
| 可控性：通过相位调整实现波束赋形 | 天线尺寸限制：高增益需大物理尺寸 |

### 注意事项
1. 天线方向图需与波束扫描技术协同设计
2. 需考虑大气折射对方向图的影响
3. 副瓣电平需控制在-20dB以下以减少干扰

## 原文证据
> 天线对于不同方向到达的电磁波具有不同的振幅和相位的响应

> F(θ) ≤ F(0), ∀θ ∈ [−π, π]

> F(θ) = F(−θ), ∀θ ∈ [−π, π]

> 半功率宽度θ0.5描述主瓣宽度，典型函数包括余弦、高斯、辛克函数
