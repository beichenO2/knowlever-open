编译链路 & 技术栈

7-Stage Pipeline (raw → website + PDF)

  1. Crystallize — 原始文档 → 知识原子 (LLM: qwen3-coder-plus via PolarPrivate)
  2. Embed & Cluster — 原子向量化 + HDBSCAN/Ward 层次聚类 (Python: UMAP, HDBSCAN, scipy Ward linkage)
  3. Tree Construct — 聚类 → 知识树 (rule-based + LLM 标签)
  4. Page Compose — 知识树 + 原子 → wiki/*.md (LLM: qwen3-coder-plus, 五段故事弧)
  5. Link Validate — wiki-link 白名单校验 + 死链检测
  6. Site Build — wiki/*.md → output/*.html (Node.js, markmap, D3.js, Mermaid 11.x)
  7. PDF Compose — wiki/*.md → pdf/*.pdf
    子链路: normalize-formulas (LLM→LaTeX) → PolarDesign doc/report (KaTeX SSR, polar-soft) → AutoOffice html-to-pdf (Playwright/Chromium)
