# 2025课后作业6 — 练习题

## 题 1

1. 下图为两种信号的模糊度图，请分别指出长脉冲、短脉冲及线性调频脉冲的
距离和速度分辨特征，并说明在雷达系统设计时如何选取信号参数。

<details>
<summary>查看解答</summary>

1. 距离与速度分辨率的基本关系式
雷达信号的距离分辨率 $\Delta R$ 与速度分辨率 $\Delta v$ 分别由信号带宽 $B$ 和相干处理时间（脉冲宽度）$T$ 决定：
$$ \Delta R = \frac{c}{2B} $$
$$ \Delta v = \frac{\lambda}{2T} \quad \text{或} \quad \Delta f_d = \frac{1}{T} $$
其中 $c$ 为光速，$\lambda$ 为载波波长，$\Delta f_d$ 为多普勒频率分辨率。

2. 三种信号的模糊度图特征分析
（1）短脉冲信号
- 特征：脉冲宽度 $\tau$ 小，等效带宽 $B \approx 1/\tau$ 较小。
- 距离分辨率：$\Delta R$ 小（高），模糊度图沿时延轴（$\tau$ 轴）主瓣窄。
- 速度分辨率：$\Delta v$ 大（低），模糊度图沿多普勒轴（$f_d$ 轴）主瓣宽。
- 图形形态：呈沿 $\tau$ 轴方向的“刀刃”状，距离分辨优但速度分辨差。

（2）长脉冲信号
- 特征：脉冲宽度 $T$ 大，带宽 $B$ 小。
- 距离分辨率：$\Delta R$ 大（低），模糊度图沿 $\tau$ 轴主瓣宽。
- 速度分辨率：$\Delta v$ 小（高），模糊度图沿 $f_d$ 轴主瓣窄。
- 图形形态：呈沿 $f_d$ 轴方向的“刀刃”状，速度分辨优但距离分辨差。

（3）线性调频（LFM）脉冲信号
- 特征：脉冲宽度 $T$ 大，同时通过频率调制获得大带宽 $B = K T$（$K$ 为调频斜率）。
- 距离分辨率：$\Delta R = c/(2B)$，由带宽决定，分辨率高。
- 速度分辨率：$\Delta v = \lambda/(2T)$，由脉宽决定，分辨率高。
- 图形形态：模糊度图呈倾斜的“斜脊”状，存在距离-多普勒耦合。主瓣在 $\tau$-$f_d$ 平面内沿斜率 $f_d/\tau = -K$ 方向延伸。

3. 雷达系统设计时的参数选取原则
（1）指标驱动：若侧重测距精度，优先增大带宽 $B$；若侧重测速精度，优先增大相干积累时间 $T$。
（2）波形选择：需同时兼顾高距离与高速度分辨率时，采用 LFM 或相位编码等脉冲压缩波形。利用匹配滤波将长脉冲压缩为窄脉冲，突破简单脉冲的分辨率制约。
（3）耦合与模糊控制：LFM 的距离-多普勒耦合可通过信号处理（如去斜、多普勒补偿）消除；为避免距离/速度模糊，需结合模糊函数主瓣宽度合理设计脉冲重复频率（PRF），常采用参差 PRF 或中/高 PRF 体制。
（4）工程折中：在发射功率、射频带宽、数字处理算力约束下，通过模糊函数等高线图验证旁瓣电平与主瓣形状，迭代优化 $B$、$T$ 及调制参数。

4. 参数计算示例
假设某雷达设计要求：$\Delta R \le 15\,\text{m}$，$\Delta v \le 1\,\text{m/s}$，工作频率 $f_0 = 10\,\text{GHz}$（$\lambda = 0.03\,\text{m}$）。
- 所需最小带宽：$B \ge \frac{c}{2\Delta R} = \frac{3\times 10^8}{2\times 15} = 10\,\text{MHz}$
- 所需最小脉宽：$T \ge \frac{\lambda}{2\Delta v} = \frac{0.03}{2\times 1} = 0.015\,\text{s} = 15\,\text{ms}$
选取 LFM 信号，令 $B=10\,\text{MHz}$，$T=15\,\text{ms}$，调频斜率 $K = B/T \approx 0.667\,\text{MHz/ms}$。经匹配滤波后，距离分辨率可达 $15\,\text{m}$，速度分辨率可达 $1\,\text{m/s}$，满足设计指标。

</details>

## 题 2

2. 已知某 6 位编码雷达信号波形 s(t)如下图所示。
① 请画出其匹配滤波器的冲激响应 h(t ) 。

② 若有雷达回波信号 $s_1(t) = 2s(t - \tau_0) - 5s(t - \tau_1)$，$s_2(t) = 3s(t - \tau_2)e^{-j 2\pi f d t}$，

请分别说明①中的匹配滤波器是否对 $s_1(t)$ 和 $s_2(t)$ 具有最大信噪比输出，若不能 /think

输出最大信噪比，应如何设计对应的 h(t ) ？

<details>
<summary>查看解答</summary>

**① 匹配滤波器冲激响应 $h(t)$ 的绘制**

根据匹配滤波器理论，在加性白高斯噪声（AWGN）背景下，使输出信噪比最大的线性滤波器的冲激响应为：
$$h(t) = k s^*(t_0 - t)$$
为保证物理可实现性（因果性），通常取采样时刻 $t_0 = T$（$T$ 为信号 $s(t)$ 的总持续时间），并令增益常数 $k=1$。因此：
$$h(t) = s^*(T - t), \quad 0 \le t \le T$$
**绘图说明**：$h(t)$ 是 $s(t)$ 的**共轭时间反转**波形。若 $s(t)$ 为实编码信号（如二相码），则 $h(t)$ 仅为时间反转。具体而言，若 $s(t)$ 由 6 个等宽子脉冲组成，各码元值依次为 $c_1, c_2, \dots, c_6$，则 $h(t)$ 的 6 个子脉冲顺序为 $c_6, c_5, \dots, c_1$。在时域坐标系中，将原波形沿 $t=T/2$ 垂直轴镜像翻转即可得到 $h(t)$。

---

**② 对 $s_1(t)$ 和 $s_2(t)$ 的最大信噪比分析及设计**

**(1) 对 $s_1(t) = 2s(t - \tau_0) - 5s(t - \tau_1)$**
- **结论**：①中的匹配滤波器对 $s_1(t)$ **具有**最大信噪比输出（针对各独立分量）。
- **分析**：匹配滤波器是线性时不变系统。将 $s_1(t)$ 输入该滤波器，输出为各分量响应的线性叠加：
  $$y_1(t) = 2R_{ss}(t - \tau_0) - 5R_{ss}(t - \tau_1)$$
  其中 $R_{ss}(\tau)$ 为 $s(t)$ 的自相关函数。该滤波器对 $s_1(t)$ 中的每一个延迟分量均能独立实现最大信噪比输出。雷达实际处理中，多目标回波仍统一使用针对发射波形 $s(t)$ 设计的匹配滤波器，输出呈现多个相关峰，分别对应不同距离的目标。

**(2) 对 $s_2(t) = 3s(t - \tau_2)e^{-j 2\pi f_d t}$**
- **结论**：①中的匹配滤波器对 $s_2(t)$ **不能**提供最大信噪比输出。
- **分析**：$s_2(t)$ 存在多普勒频移 $f_d$。①中的滤波器是针对基带信号 $s(t)$ 设计的，与 $s_2(t)$ 存在频率失配。频偏会导致脉压主瓣展宽、峰值下降，输出信噪比显著降低（衰减程度取决于波形的多普勒容限）。
- **设计方法**：为获得最大信噪比，需针对 $s_2(t)$ 重新设计匹配滤波器。根据定义：
  $$h_2(t) = s_2^*(T - t) = 3 s^*(T - t + \tau_2) e^{j 2\pi f_d (T - t)}, \quad 0 \le t \le T$$
  该滤波器在时域上不仅包含 $s(t)$ 的时间反转，还引入了与多普勒频移共轭的复指数项 $e^{j 2\pi f_d (T - t)}$ 以精确补偿频偏。工程实现中，通常采用**多普勒滤波器组**（一组中心频率覆盖预期 $f_d$ 范围的匹配滤波器）或**脉压后接多普勒处理（如FFT）**，以确保对运动目标的最大信噪比输出。

</details>

## 题 3

3. 请画出相参脉冲串和非相参脉冲串信号的最佳检测框图，指出两种信号在处
理上的区别，并解释其原因。

<details>
<summary>查看解答</summary>

### 一、 信号模型与最佳检测原理
设接收信号为 $r(t)=s(t)+n(t)$，$n(t)$ 为功率谱密度 $N_0/2$ 的加性高斯白噪声。
- **相参脉冲串**：各脉冲载波相位具有确定关系（通常恒定或线性变化），可表示为
  $s_c(t)=\sum_{n=0}^{N-1}p(t-nT_r)e^{j(2\pi f_c t+\phi_0)}$
- **非相参脉冲串**：各脉冲载波相位相互独立且服从 $[0,2\pi)$ 均匀分布，
  $s_{nc}(t)=\sum_{n=0}^{N-1}p(t-nT_r)e^{j(2\pi f_c t+\phi_n)}$

根据Neyman-Pearson准则，最佳检测器由匹配滤波器与似然比检验导出。相位先验信息的有无直接决定积累域与检波顺序。

### 二、 最佳检测框图
**1. 相参脉冲串最佳检测框图**
```
接收信号 r(t) → [正交下变频(I/Q)] → [匹配滤波器] → [相干积累器(复数相加)] → [幅度检测] → [门限比较器] → 判决输出
```
*(注：匹配滤波器与相干积累可合并为脉冲压缩+多脉冲相干处理；幅度检测通常为取模或平方后开方)*

**2. 非相参脉冲串最佳检测框图**
```
接收信号 r(t) → [正交下变频(I/Q)] → [匹配滤波器] → [平方律检波器] → [非相干积累器(线性相加)] → [门限比较器] → 判决输出
```
*(注：平方律检波为未知随机相位下的最优非线性变换；积累器对检波后的功率值进行线性累加)*

### 三、 处理上的区别
| 对比维度         | 相参脉冲串检测                     | 非相参脉冲串检测                     |
|------------------|------------------------------------|--------------------------------------|
| **积累位置**     | 检波前（基带复数域）               | 检波后（实数幅度/功率域）            |
| **积累运算**     | 复数相加（保留相位）               | 实数相加（丢弃相位）                 |
| **信噪比改善**   | $SNR_{\text{out}} = N \cdot SNR_{\text{in}}$ | $SNR_{\text{out}} = \eta(N, SNR_{\text{in}}) \cdot N \cdot SNR_{\text{in}}$，其中 $\eta < 1$ 为积累损失因子 |
| **相位要求**     | 需精确载频同步与相位补偿           | 无需相位同步，对频偏/相位抖动鲁棒    |

### 四、 原因解释
1. **似然比检验的数学本质**：
   - 相参信号相位已知，接收信号在复平面上的投影方向固定。匹配滤波器输出为复高斯变量，直接进行复数相加可使信号幅度线性叠加（$\propto N$），噪声功率仅按方差叠加（$\propto N$），故输出信噪比严格提升 $N$ 倍，实现能量最优聚焦。
   - 非相参信号相位 $\phi_n$ 为随机变量，若直接复数相加会导致信号矢量随机相消。对随机相位信号求似然比需对相位积分，推导结果等价于先对匹配滤波器输出取包络（平方律检波消除相位依赖性），再对功率值积累。

2. **非线性检波引入的积累损失**：
   平方律检波 $y=|x|^2$ 是非线性操作，会将噪声与信号的交叉项转化为直流与低频分量。积累过程中噪声功率的统计起伏无法完全抵消，导致有效信噪比增益低于 $N$。积累损失 $\eta$ 随 $N$ 增大和输入信噪比降低而加剧（例如 $N=10$、$SNR_{\text{in}}=0\text{dB}$ 时，$\eta \approx 0.6\sim0.7$）。

3. **工程与理论的权衡**：
   相参处理性能最优但对系统相参性（本振稳定度、运动补偿精度）要求苛刻；非相参处理牺牲部分信噪比换取对相位不确定性的容忍度，适用于目标机动剧烈或本振相参性不足的场景。两者框图差异本质上是**相位先验信息是否可利用**在检测器结构上的直接映射。

</details>

## 题 4

4. 请分别画出一个慢门限恒虚警和一个快门限恒虚警的原理框图，并分别说明
其处理对象的特点及各自的工作机理？

<details>
<summary>查看解答</summary>

### 一、慢门限恒虚警（Slow CFAR）

**1. 原理框图**
```
雷达回波 → [包络检波/平方律检波] → [延迟线（对齐CUT）] → [长参考窗] → [低通/递归积分器] → [×T] → [门限] → [比较器] → 检测输出
                                                              ↑
                                                          反馈回路
```
**2. 处理对象特点**
- 适用于背景杂波或噪声功率**变化缓慢、空间/时间分布均匀**的环境（如平稳海杂波、热噪声主导区）。
- 不适用于杂波边缘、强干扰突变区或多目标密集区，易出现目标遮蔽或边缘虚警。

**3. 工作机理**
- 采用**长积分时间常数**（$\tau \gg$ 脉冲重复周期），通常由一阶递归滤波器实现：
  $\hat{P}_n = \alpha \hat{P}_{n-1} + (1-\alpha) Z_n$，其中 $\alpha \approx 1$，$Z_n$ 为参考窗内单元功率均值。
- 门限由背景功率估计值乘以恒虚警系数 $T$ 得到：$V_{\text{th}} = T \cdot \hat{P}_n$。$T$ 由期望虚警概率 $P_{\text{fa}}$ 与噪声统计分布（如指数分布）决定，例如对CA-CFAR有 $T = N(P_{\text{fa}}^{-1/N}-1)$。
- 长积分有效平滑短期起伏，使门限更新缓慢，在均匀背景下能严格维持 $P_{\text{fa}}$ 恒定，但动态响应迟钝。

---

### 二、快门限恒虚警（Fast CFAR）

**1. 原理框图**
```
雷达回波 → [包络检波/平方律检波] → [延迟线（对齐CUT）] → [短参考窗] → [滑动平均/排序估计器] → [×T] → [门限] → [比较器] → 检测输出
```
**2. 处理对象特点**
- 适用于背景功率**变化剧烈、存在杂波边缘或局部非均匀**的环境（如海岸线过渡区、气象杂波突变区）。
- 对快速起伏敏感，但短窗易受邻近强目标干扰，可能在边缘处产生虚警簇或漏检。

**3. 工作机理**
- 采用**短积分时间常数**（$\tau$ 接近或略大于相干处理间隔），通常由短滑动窗（FIR）或顺序统计量（OS-CFAR）实现：
  $\hat{P}_n = \frac{1}{M} \sum_{k=1}^{M} x_k^2$（$M$ 较小，通常 $M \leq 16$）。
- 门限同样为 $V_{\text{th}} = T \cdot \hat{P}_n$，但 $T$ 需根据短窗长度 $M$ 及所选统计量重新标定以维持 $P_{\text{fa}}$。
- 短窗使门限能快速跟踪局部背景功率变化，适应非均匀环境；但缺乏平滑能力，对噪声短期波动敏感，需配合边缘保护单元或自适应 $T$ 调整以抑制虚警。

---

**核心对比要点**
- 时间常数：慢门限 $\tau$ 大（递归/长窗），快门限 $\tau$ 小（滑动/短窗）。
- 适用场景：慢门限重“稳”，快门限重“快”。
- 恒虚警实现：均依赖 $V_{\text{th}}=T\hat{P}_n$，但 $T$ 的标定与 $\hat{P}_n$ 的估计结构随门限更新速度不同而差异化设计。

</details>
