1. **信号与滤波器建模**
   输入信号为矩形脉冲：
   $$s(t) = \begin{cases} A, & 0 \le t \le \tau \\ 0, & \text{其他} \end{cases}$$
   其傅里叶变换为：
   $$S(\omega) = \int_{0}^{\tau} A e^{-j\omega t} dt = A\tau \cdot \text{Sa}\left(\frac{\omega\tau}{2}\right) e^{-j\omega \tau/2}$$
   其中 $\text{Sa}(x) = \frac{\sin x}{x}$。幅度谱零点位于 $\omega_k = \frac{2k\pi}{\tau} \ (k=\pm1,\pm2,\dots)$。

   匹配滤波器冲激响应定义为
$$h(t) = C s^*(t_0 - t)$$
。为保证因果性取 $t_0 = \tau$，信号为实信号故 $s^*(t)=s(t)$。结合图中 $h(t)$ 幅值为 $1$，取归一化常数 $C = 1/A$，得：
   $$h(t) = \frac{1}{A} s(\tau - t) = \begin{cases} 1, & 0 \le t \le \tau \\ 0, & \text{其他} \end{cases}$$
   对应频率响应：
   $$H(\omega) = \int_{0}^{\tau} e^{-j\omega t} dt = \tau \cdot \text{Sa}\left(\frac{\omega\tau}{2}\right) e^{-j\omega \tau/2}$$
   满足匹配滤波器频域关系 $H(\omega) = C S^*(\omega) e^{-j\omega t_0}$。

2. **时域输出计算**
   输出信号为卷积 $s_0(t) = s(t) * h(t) = \int_{-\infty}^{\infty} s(\lambda) h(t-\lambda) d\lambda$。
   两个宽度均为 $\tau$ 的矩形脉冲卷积，结果为底宽 $2\tau$、峰值位于 $t=t_0=\tau$ 的三角脉冲：
   $$s_0(t) = \begin{cases} A t, & 0 \le t < \tau \\ A(2\tau - t), & \tau \le t < 2\tau \\ 0, & \text{其他} \end{cases}$$
   峰值时刻 $t=\tau$ 处的数值结果为：
   $$s_0(\tau) = A\tau$$

3. **频域匹配原理分析**
   由 $H(\omega)$ 与 $S(\omega)$ 的表达式可知：
   $$|H(\omega)| = \frac{1}{A} |S(\omega)|$$
   即滤波器幅频特性与信号幅度谱成正比。信号能量集中的频段（如 $\omega=0$ 附近主瓣），$|S(\omega)|$ 大，滤波器增益 $|H(\omega)|$ 亦大；信号能量弱的频段（如旁瓣或零点附近），增益相应降低。此即“越强的信号分量，增益越高”的数学本质。

4. **物理意义与结论**
   在加性白高斯噪声背景下，该设计使输出信噪比在 $t_0=\tau$ 时刻达到理论最大值：
   $$\text{SNR}_{\max} = \frac{2E}{N_0} = \frac{2A^2\tau}{N_0}$$
   其中 $E = \int_0^\tau |s(t)|^2 dt = A^2\tau$ 为信号能量。匹配滤波器通过时域翻转对齐实现信号相干叠加，通过频域共轭加权实现噪声非相干抑制，最终在 $t_0$ 处输出尖锐峰值，完成最佳检测。

**步骤1：明确信号模型与相参积累输出**
设MTI处理后的离散脉冲串信号为：
$$y(n) = cA e^{j[2\pi f_d (n-1)T + \varphi_0]}, \quad n = K+1, K+2, \dots, N$$
其中 $c$ 为复常数，$A$ 为幅度，$f_d$ 为多普勒频移，$T$ 为脉冲重复周期，$\varphi_0$ 为初始相位。
相参积累采用的加权系数为：
$$w(n) = e^{-j 2\pi f_d (n-1)T} \cdot e^{j 2\pi f_d k T}$$
相参积累的输出为加权和：
$$P = \sum_{n=K+1}^{N} w(n) y(n)$$
代入 $y(n)$ 与 $w(n)$ 可消去多普勒相位项，得到相干叠加结果 $P = (N-K)cA e^{j\alpha_0}$（$\alpha_0$ 为累积常数相位）。

**步骤2：构造匹配滤波器**
在加性白高斯噪声背景下，使输出信噪比最大的最佳线性滤波器为匹配滤波器。对信号 $y(n)$ 的匹配滤波器冲激响应定义为：
$$h(n) = C y^*(n_0 - n)$$
其中 $n_0$ 为选定的输出信噪比峰值时刻，$C$ 为任意非零复常数，$^*$ 表示复共轭。

**步骤3：计算匹配滤波器在峰值时刻的输出**
匹配滤波器的输出为离散卷积：
$$P(n) = h(n) * y(n) = \sum_{i=K+1}^{N} h(n-i) y(i) = \sum_{i=K+1}^{N} C y^*[n_0 - (n-i)] y(i)$$
令 $n = n_0$，此时滤波器输出达到信噪比最大值：
$$P(n_0) = \sum_{i=K+1}^{N} C y^*(i) y(i)$$

**步骤4：证明匹配滤波权值与相参积累权值等价**
将 $y(i)$ 的表达式代入 $C y^*(i)$ 进行推导。取常数 $C$ 为：
$$C = \frac{1}{(cA)^*} e^{j(2\pi f_d k T + \varphi_0)}$$
计算 $C y^*(i)$：
$$y^*(i) = (cA)^* e^{-j[2\pi f_d (i-1)T + \varphi_0]}$$
$$C y^*(i) = \left[ \frac{1}{(cA)^*} e^{j(2\pi f_d k T + \varphi_0)} \right] \cdot \left[ (cA)^* e^{-j[2\pi f_d (i-1)T + \varphi_0]} \right]$$
$$= e^{-j 2\pi f_d (i-1)T} \cdot e^{j 2\pi f_d k T}$$
对比步骤1中的定义，该结果恰好等于相参积累的加权系数 $w(i)$，即：
$C y^*(i) = w(i)$

**步骤5：结论**
将权值等价关系代入步骤3的匹配滤波输出表达式：
$$P(n_0) = \sum_{i=K+1}^{N} w(i) y(i) = P$$
由此可见，脉冲串相参积累的数学运算形式与匹配滤波器在最大信噪比时刻的输出完全一致。根据匹配滤波理论，该结构在加性白噪声下可使输出信噪比最大化。因此，**脉冲串的相参积累等效于匹配滤波，属于最佳滤波**。
